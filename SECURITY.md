# Security

The programs read files the player chooses (the Xbox disc image, the GameCube and PlayStation 2 discs for the guests,
`settings.ini`, saves) and, in online play, packets from the other player and answers from the online service. A
file or a packet that makes the game or the launcher read or write outside its own memory, or start another program,
is a real bug and worth a private report.

Please report such a thing privately through GitHub ("Report a vulnerability" on the repository's Security tab) or to
tmcleroy@gmail.com, and not in a public issue.

Only the latest release is supported.
